# Slow coarsening of vicinal instabilities

This repository contains the accompanying numerical code to the paper
"Slow coarsening of vicinal instabilities in a B1-type model of step bunching and meandering".

Both figures in the numerical section of the paper and the supplemental video 
are fully reproducible from this repository.


## Installation of tools

We use python as our language of choice and `uv` as the package manager.

Install `uv` for your operating system by following the official documentation:

https://docs.astral.sh/uv/getting-started/installation/


## Install dependencies

Once uv is installed, you can install all necessary dependencies by running

```shell
uv sync
```


## Running the scripts

All scripts can be run individually or using the poe task runner installed in the
environment.

1. To run the PDE calculation and generate the video provided as supplementary 
information to the paper and from which the frames in Fig. 2 are obtained run:

```shell
uv run poe make_pde
```

2. To run the ODE calculation and generate the plots in Fig. 1 run
```
uv run poe make_ode
```


## Cleaning artifacts

To clean all artifacts generated by scripts run:

```
uv run poe clean
```


## Known issues

On Windows the Newton-Krylov solver from scipy in the PDE-code fails with an 
error due to a solver bug. Run under WSL to mitigate this issue.
